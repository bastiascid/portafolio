## 📌 Descripción

Este es mi portafolio personal interactivo, donde presento mi perfil profesional como Ingeniero en Ejecución Informática y Docente, junto con mis proyectos destacados, habilidades, certificaciones y experiencia laboral.

El sitio está diseñado para ser completamente responsivo, rápido y ofrecer una experiencia de usuario inmersiva con animaciones modernas y diseño minimalista (Glassmorphism).

## 🚀 Características

- **Secciones Integradas:** Inicio, Sobre Mí, Servicios, Proyectos, Educación, Experiencia y Contacto.
- **Integración con GitHub:** Los proyectos se obtienen dinámicamente utilizando la API de GitHub.
- **Modo Oscuro/Claro:** Soporte para cambiar el tema de la aplicación.
- **Formulario de Contacto:** Conectado a FormSubmit.
- **Botón Flotante:** Acceso rápido a contacto vía WhatsApp.

## 🛠 Tecnologías Utilizadas

- **Frontend:** HTML5 Semántico, CSS3 (Variables, Flexbox, Grid, Animaciones, Glassmorphism), JavaScript (Vanilla).
- **Iconos y Fuentes:** FontAwesome, Google Fonts (Outfit, Inter).
- **APIs:** GitHub REST API.

## 📦 Instalación Local

1. **Clona el repositorio:**
   ```bash
   git clone https://github.com/bastiascid/portafolio.git
   ```

2. **Abre el proyecto:**
   Simplemente abre el archivo `index.html` en tu navegador moderno preferido. Para probar el consumo de API sin problemas de CORS, se recomienda usar una extensión como "Live Server" en VS Code.
